# grilling

Adapted from [mattpocock's grilling skill](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md), with two tweaks: each round asks only 2–4 sibling questions from the same parent decision instead of the whole frontier, and while a fact-finding sub-agent runs, we continue with the current cluster, skipping only questions that depend on it.
